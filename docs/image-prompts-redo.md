# Image prompts — regenerating pages 02–16

210 images, fourteen per page. Page 01 is deliberately not here: its
fourteen came back correct and are already on the site.

## Why these are being redone

The delivered set was measured, and 181 of 224 had text rendered into the
picture while 136 had content sliced off at an edge. What came back were
marketing banners — a headline, a subhead, a row of labelled icons — then
cropped to 16:9, which cut the headline mid-word. On the hire page
"Agentic AI Developers" arrives as "ntic AI / elopers".

Two reasons that does not work here. The pictures sit about 400px wide, so
baked-in words are unreadable anyway. And text inside a JPEG cannot be
read by a search engine or translated — this site answers in six
languages, and a headline burned into an image stays English forever.

Page 01 proves the brief is achievable: all fourteen of its images came
back clean under the same instructions.

## How to use

1. Start a NEW chat. Paste the STYLE BLOCK below as the first message,
   on its own.
2. Then send one SUBJECT line at a time — only the words after the dash.
   Do not paste the filename: it can make the model render the filename
   into the picture, which is exactly the fault being fixed.
3. Save each result under the filename shown beside it.

Keep it to one conversation per run, and re-paste the style block if you
start a new chat. That is what holds the sets together as one website.

**Reject and retry any image that has words in it, a border or white
margin, or a subject running off the edge.** Replying "again — no text at
all, abstract object only, nothing touching the edges" usually fixes it.
If the model keeps producing banners, start a fresh chat and re-paste the
style block; it has usually anchored on an earlier answer.

## STYLE BLOCK

```
Original abstract 3D render. Fills the entire 16:9 landscape frame, edge to edge, with no border, no white margin and no padding of any kind. Near-black navy background (hex 0B0F17). Light comes only from the subject: glowing cyan (hex 00F2FE) through blue (hex 4EA8FF) into violet (hex 9D4EDD). Cinematic studio lighting, soft depth of field, subtle volumetric haze, clean reflective floor, premium enterprise feel. Bold, simple, large forms that stay readable when the image is shown small; avoid thin hairlines and fine detail. The subject sits fully inside the frame with clear empty space around it, and nothing touches or runs off any edge. ABSOLUTELY NO TEXT of any kind: no words, no letters, no numbers, no labels, no captions, no headings, no titles, no watermarks, no logos, no brand marks, no user interface, no buttons, no charts, no diagrams with labels. This is NOT a poster, NOT a banner, NOT a slide, NOT an infographic and NOT a screenshot. It is a single abstract sculptural object rendered in 3D. No people, no faces, no hands, no photography.
```
